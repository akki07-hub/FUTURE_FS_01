002 // Selected work

Things I’ve shipped.

Project 01

SmartLab AR

Augmented reality • Android • Unity

An AR lab layout designer for Android phones. Scan a room, then place desks, lab tables, chairs, monitors, CPU towers, keyboards, mice and networking equipment on detected floors and desk tops, and see the lab before it’s built.

  • Objects stay fixed in the room with AR anchors, and can be moved, rotated 45°, duplicated or deleted
  • Monitors, CPUs, keyboards and mice stack onto desks and tables
  • Equipment catalogue with categories, plus measure, layout, undo and save tools
  • Unity
  • C#
  • AR Foundation
  • ARCore

Project 02

VR Computer Lab Tour

Virtual reality • Meta Quest • Unity 6

A virtual-reality tour of a college computer lab for Meta Quest. Walk around four workstations, point at any computer to highlight it and open a panel with its hardware specifications, or follow a guided tour.

  • Smooth movement, snap turn and teleport with collision
  • Welcome screen and a 7-step guided tour with markers
  • Automated play-mode tests and a built Quest APK
  • Unity 6
  • C#
  • OpenXR
  • XR Interaction Toolkit

Full-stack • REST API • MERN

A college event management system. Organizers create events, students register, and the app enforces seat limits, blocks duplicate sign-ups and tracks every participant. Built with an 18-endpoint REST API, a Postman collection and a 35-page project report.
